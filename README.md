# Abdallah Gharaibeh — Cybersecurity Portfolio

A bilingual (English/Arabic), responsive, terminal-inspired personal portfolio.

## Preview locally
Open `index.html` in your browser. No build tools are required.

## Before publishing
1. Replace the example GitHub and LinkedIn URLs with your actual profiles.
2. Replace `your.email@example.com` with your public contact email.
3. TryHackMe profile is currently set to `https://tryhackme.com/p/abboudissagh-ux`.
4. Instagram is currently set to `https://www.instagram.com/abdallah_j_gharaibeh/`.
5. Replace the starter project descriptions with completed projects and real repository links.
6. Review the skills list so it accurately reflects your current proficiency.

## Publish with GitHub Pages
1. Create a GitHub repository named `your-username.github.io` (or any repository for a project site).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. For a project repository: open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish and open the URL shown in the Pages settings.
